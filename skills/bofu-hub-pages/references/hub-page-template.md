# Hub page template with a worked example

Fictional brand: TallyLeaf, invoicing software. All pages and facts below are invented.

## Spec

```
Hub URL: /uses/
Title: Uses | TallyLeaf
H1: Ways to Use TallyLeaf
Intro: Get paid on time without a spreadsheet. These are the most common ways freelancers, studios and small teams use TallyLeaf to invoice.
```

## Groups and links

### For freelancers
- Invoice Software for Freelancers (/uses/invoice-software-for-freelancers)
- Invoice Template With Automatic Reminders (/uses/invoice-template-with-automatic-reminders)
- Time Tracking and Invoicing for Designers (/uses/time-tracking-and-invoicing-for-designers)

### For agencies and studios
- Recurring Invoices for Agencies (/uses/recurring-invoices-for-agencies)
- Multi-Currency Invoicing for Studios (/uses/multi-currency-invoicing-for-studios)

### Payments and reminders
- Accept Card Payments on Invoices (/uses/accept-card-payments-on-invoices)
- Late Payment Reminder Software (/uses/late-payment-reminder-software)

CTA at the bottom: "Start free" button linking to the signup page.

## Layout notes

- Order inside "For freelancers": highest demand first, then most relevant to the group, with the near-duplicate "invoice template" page apart from the two software pages.
- Footer: a "Use cases" column links to /uses/, plus direct links to the top 3 landing pages.
- Each landing page links back to /uses/ in its breadcrumb, and to two related pages in a "Related uses" block.
- Depth: home (0) > /uses/ (1) > landing page (2).

## Anchor text rule

Use the target page's H1 as the anchor. If two H1s are too similar, adjust one anchor slightly (for example add the audience), but do not use "learn more".
